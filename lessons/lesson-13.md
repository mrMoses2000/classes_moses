# Занятие 13: «Arduino: Аналоговые сигналы, АЦП и ШИМ — зрение робота и плавный ход»

Сценарий очного занятия для способного ученика 4 класса (55–60 минут)  
**Уровень сложности:** Высокий инженерный (аналого-цифровой преобразователь АЦП 10-бит, широтно-импульсная модуляция ШИМ, делитель напряжения).  
**Траектория:** Этап 3. «Компьютер и Arduino» → Непрерывные физические величины и управление исполнительными механизмами.

---

## 1. Место урока в общей траектории

- **Конечная способность из `LEARNING_VISION.md`:** Различать дискретный (цифровой) и непрерывный (аналоговый) сигналы; использовать аналого-цифровой преобразователь (АЦП `analogRead`) для измерения освещенности или положения ручки; преобразовывать диапазоны математической функцией `map()`; управлять мощностью двигателей или яркостью фар с помощью ШИМ (`analogWrite`).
- **Текущий этап:** Завершение аппаратной части Этапа 3 перед переходом к сетям и финальному проекту.
- **Прошлый освоенный навык (Занятия 11–12):** Ученик уверенно управляет дискретным выводом (`HIGH/LOW`) и считывает кнопку с антидребезгом.
- **Причина выбора темы:** Реальный мир не состоит из одних только нулей и единиц (светло/темно, нажат/отпущен). Реальный мир непрерывен: солнце восходит плавно, препятствие приближается постепенно, колесо робота может крутиться медленно или быстро. Мы знакомим ученика с **АЦП (переводчиком физики в числа 0–1023)** и **ШИМ (хитрым импульсным регулятором мощности 0–255)**.

---

## 2. Главная учебная цель и проверяемый результат

- **Главная учебная цель:** Освоить чтение аналогового напряжения пинами `A0–A5` (числа 0–1023) и генерацию ШИМ-сигнала на пинах с тильдой `~` (числа 0–255); построить систему «автоматический ночник» и плавный регулятор яркости (диммер).
- **Проверяемый результат (действие ребёнка без подсказки):**
  1. Объясняет, почему АЦП выдаёт число от 0 до 1023: *$2^{10} = 1024$ градаций, где 0 — это 0 Вольт, а 1023 — это 5 Вольт*.
  2. Самостоятельно находит на плате пины с пометкой `~` (3, 5, 6, 9, 10, 11) и объясняет, что обычные пины могут выдавать только 0 или 5V, а ШИМ-пины быстро моргают, создавая иллюзию промежуточного напряжения.
  3. Использует функцию масштабирования `map(sensor, 0, 1023, 0, 255)` для прямой передачи показания датчика света в яркость светодиода.

## 4. Практические задания со скетчами

### Задание 1. «Автоматические фары марсохода (Фоторезистор)»
- **Схема делителя напряжения на макетке:**
  - `5V` ➔ `[Фоторезистор]` ➔ `[Точка A1]` ➔ `[Резистор 10 кОм]` ➔ `[GND]`.
  - Светодиод фар: `Pin 12` через 220 Ом на `GND`.
- **Скетч (`autolight.ino`):**
  ```cpp
  const int SENSOR_PIN = A1;
  const int HEADLIGHT_PIN = 12;
  const int THRESHOLD = 400; // Порог наступления темноты

  void setup() {
      Serial.begin(9600);
      pinMode(HEADLIGHT_PIN, OUTPUT);
  }

  void loop() {
      int light_level = analogRead(SENSOR_PIN); // Читаем число 0..1023

      Serial.print("Уровень освещённости: ");
      Serial.println(light_level);

      if (light_level < THRESHOLD) {
          digitalWrite(HEADLIGHT_PIN, HIGH); // Темно: включить фары!
      } else {
          digitalWrite(HEADLIGHT_PIN, LOW);  // Светло: экономим батарею
      }

      delay(100);
  }
  ```

### Задание 2. «Дышащий светодиод (ШИМ-эффект)»
- **Скетч (`breathing_led.ino`):**
  ```cpp
  const int PWM_LED = 9; // Пин с тильдой ~ (поддерживает ШИМ!)

  void setup() {
      pinMode(PWM_LED, OUTPUT);
  }

  void loop() {
      // 1. Плавное разгорание (скважность от 0% до 100%)
      for (int b = 0; b <= 255; b += 5) {
          analogWrite(PWM_LED, b);
          delay(20);
      }

      // 2. Плавное угасание
      for (int b = 255; b >= 0; b -= 5) {
          analogWrite(PWM_LED, b);
          delay(20);
      }

      delay(300); // короткий отдых
  }
  ```

### Задание 3. «Умный диммер управления мощностью»
- **Скетч связки сенсора и исполнителя (`dimmer.ino`):**
  ```cpp
  const int POT_PIN = A0;  // Вход АЦП (0..1023)
  const int LED_PIN = 9;   // Выход ШИМ (0..255)

  void setup() {
      Serial.begin(9600);
      pinMode(LED_PIN, OUTPUT);
  }

  void loop() {
      int pot_val = analogRead(POT_PIN);

      // Масштабируем диапазон: вход от 0..1023, выход от 0..255
      int brightness = map(pot_val, 0, 1023, 0, 255);

      analogWrite(LED_PIN, brightness);

      Serial.print("Потенциометр: ");
      Serial.print(pot_val);
      Serial.print(" -> ШИМ яркость: ");
      Serial.println(brightness);

      delay(50);
  }
  ```

## 7. Выходной вопрос и 4 критерия наблюдения

### Краткий выходной вопрос:
> *«В чём разница между командами digitalRead() и analogRead(), и почему у них разные диапазоны чисел?»*  
> *(Ожидаемый ответ: «digitalRead выдаёт только 0 или 1 (есть ток или нет). А analogRead измеряет силу напряжения и выдаёт число от 0 до 1023, потому что АЦП делит 5 Вольт на 1024 части»)*.

### 4 наблюдения преподавателя:
1. **Различие цифры и аналога:** Понимает физическую разницу между кнопкой и фоторезистором.
2. **Диапазоны АЦП и ШИМ:** Не путает 1023 (10 бит входа) и 255 (8 бит выхода).
3. **Понимание ШИМ:** Понимает, что плавность достигается высокой частотой импульсов.
4. **Работа с графиками:** Умеет читать Serial Plotter и находить аномалии на кривой.

## 1. Место урока в общей траектории

- **Конечная способность из `LEARNING_VISION.md`:** Создавать и модифицировать короткую компилируемую программу на C с вводом/выводом; самостоятельно запускать GCC в терминале, читать предупреждения компилятора (`-Wall`) и объяснять цепочку «исходный код `.c` → компилятор → бинарный файл ELF → запуск в ОС».
- **Текущий этап:** Ядро Этапа 2 («Текст и C на компьютере»).
- **Прошлый освоенный навык (Занятие 5):** Ученик преодолел страх перед клавиатурным набором, понимает важность регистра и точек с запятой, умеет читать номера строк с ошибками.
- **Причина выбора темы:** Язык C — фундамент современной цифровой цивилизации: на нём написаны ядро Linux, операционные системы Windows и macOS, браузер Chrome и прошивки всех микроконтроллеров. Мы переходим от учебных симуляторов к **настоящему инструменту профессиональных инженеров**: файлам `.c`, компилятору `gcc` и запуску бинарных программ в Linux.

---

## 2. Главная учебная цель и проверяемый результат

- **Главная учебная цель:** Понять жизненный цикл программы на компилируемом языке: создать исходный файл `main.c`, скомпилировать его утилитой `gcc` в исполняемый файл и запустить командой `./app`, управляя выводом через `printf()`.
- **Проверяемый результат (действие ребёнка без подсказки):**
  1. В терминале Linux самостоятельно вводит цепочку команд: `nano main.c` (или открывает в VS Code) ➔ `gcc -Wall main.c -o app` ➔ `./app`.
  2. Объясняет назначение ключевых элементов скелета C-программы: директивы `#include <stdio.h>`, точки входа `int main()`, фигурных скобок `{}` и кода завершения `return 0;`.
  3. Понимает символ переноса строки `\n` и заполнитель `%d` для вывода чисел в `printf()`.

## 4. Три практических задания в терминале

### Задание 1. «Сборка первого исполняемого файла»
- **Файл:** `~/robot_lab/hello.c`
- **Код:**
  ```c
  #include <stdio.h>

  int main() {
      printf("==============================\n");
      printf("  БОРТОВОЙ КОМПЬЮТЕР РОБОТА   \n");
      printf("  СИСТЕМА ЗАПУЩЕНА УСПЕШНО!   \n");
      printf("==============================\n");
      return 0;
  }
  ```
- **Команды терминала:**
  ```bash
  gcc hello.c -o hello
  ./hello
  ```
- **Критерий успеха:** Программа компилируется без ошибок и выводит ровную рамку в консоль.

### Задание 2. «Телеметрия марсохода: работа с числами»
- **Файл:** `~/robot_lab/telemetry.c`
- **Задача:** Вывести телеметрию робота с тремя числовыми показателями: заряд батареи, пройденное расстояние и температура процессора.
- **Код:**
  ```c
  #include <stdio.h>

  int main() {
      int battery = 87;
      int distance_meters = 1450;
      int cpu_temp = 42;

      printf("--- ТЕЛЕМЕТРИЯ ---\n");
      printf("Заряд батареи: %d%%\n", battery);
      printf("Дистанция:     %d м\n", distance_meters);
      printf("Температура:   %d C\n", cpu_temp);
      return 0;
  }
  ```
- **Усложнение:** Ученик меняет значения переменных, перекомпилирует и убеждается, что вывод меняется соответственно.

### Задание 3. «Режим строгого компилятора (-Wall -Werror)»
- **Задача:** Исправить код с предупреждениями компилятора.
- **Исходный файл с дефектами:**
  ```c
  // Забыт #include <stdio.h>
  int main() {
      int x = 10; // переменная x создана, но нигде не используется
      printf("Старт двигателей!\n");
      // забыт return 0;
  }
  ```
- **Команда компиляции:** `gcc -Wall -Werror debug.c -o debug`
- **Результат компиляции:** Компилятор отказывается собирать файл из-за флага `-Werror` (превращать все предупреждения в фатальные ошибки).
- **Действие ученика:** Добавить `#include <stdio.h>`, использовать или удалить переменную `x`, добавить `return 0;` и добиться чистой сборки.

## 7. Выходной вопрос и 4 критерия наблюдения

### Краткий выходной вопрос:
> *«Почему мы не можем просто запустить файл main.c напрямую, как текстовый документ, а обязательно должны вызвать gcc?»*  
> *(Ожидаемый ответ: «Потому что процессор не понимает английский текст. Компилятор gcc переводит наш текст в машинный код — команды из нулей и единиц, понятные микропроцессору»)*.

### 4 наблюдения преподавателя:
1. **Терминальная ориентация:** Не путается между именем исходника `main.c` и исполняемым файлом `./app`.
2. **Понимание структуры C:** Запоминает каркас `#include <stdio.h>`, `int main() { ... return 0; }`.
3. **Форматный вывод:** Корректно связывает спецификатор `%d` с переменной в списке аргументов `printf`.
4. **Осознанность ошибок:** Читает предупреждения GCC и понимает их смысл.

# Занятие 7: «C: переменные int, ввод scanf и ветвления if / else — шлюз доступа и кодовый замок»

Сценарий очного занятия для способного ученика 4 класса (55–60 минут)  
**Уровень сложности:** Повышенный (интерактивный ввод с клавиатуры, логические операторы `&&` / `||`, классическая ловушка `=` против `==`).  
**Траектория:** Этап 2. «Текст и C на компьютере» → Логические ветвления и валидация пользовательских данных.

---

## 1. Место урока в общей траектории

- **Конечная способность из `LEARNING_VISION.md`:** Создавать интерактивную программу на C с вводом данных пользователем, ветвлениями `if / else if / else` и сложными логическими условиями; предсказывать обе ветви выполнения до запуска; находить и устранять ошибки присваивания вместо сравнения.
- **Текущий этап:** Этап 2 («Текст и C на компьютере»).
- **Прошлый освоенный навык (Занятие 6):** Ученик умеет создавать файл `.c`, компилировать через `gcc -Wall`, запускать бинарник в Linux и выводить данные через `printf()`.
- **Причина выбора темы:** До сих пор программы были «глухими»: они выводили заранее зашитые числа. Но настоящий бортовой компьютер робота должен опрашивать датчики и реагировать на команды оператора в реальном времени. Мы вводим функцию ввода `scanf()` и строим **интерактивную систему шлюза безопасности**: программа ждет ввода секретного пин-кода или показания сенсора, анализирует число и выбирает одну из нескольких веток.

---

## 2. Главная учебная цель и проверяемый результат

- **Главная учебная цель:** Освоить интерактивный ввод данных (`scanf`) и многовариантное ветвление (`if / else if / else`), понять смысл амперсанда `&` (адрес ячейки памяти) и навсегда уяснить разницу между присваиванием `=` и сравнением `==`.
- **Проверяемый результат (действие ребёнка без подсказки):**
  1. Самостоятельно пишет вызов `scanf("%d", &pin);` и объясняет, зачем перед переменной стоит значок `&`: *«Это адрес ячейки в памяти, куда scanf должен положить набранное число»*.
  2. Строит трёхступенчатую логику: шлюз открыт (`pin == 777`), тревога при превышении попыток, неверный код.
  3. В задаче с ошибкой `if (code = 123)` сразу определяет дефект: *«Здесь одно равно, это перезапись переменной, а для проверки нужно двойное равно == !»*.

## 4. Три практических задания

### Задание 1. «Электронный замок шлюза»
- **Файл:** `~/robot_lab/airlock.c`
- **Код программы:**
  ```c
  #include <stdio.h>

  int main() {
      int code = 0;

      printf("ВНИМАНИЕ! Вход в шлюзовой отсек.\n");
      printf("Введите четырёхзначный ключ допуска: ");
      scanf("%d", &code);

      if (code == 2026) {
          printf("[ДОСТУП РАЗРЕШЁН] Шлюз разблокирован. Добро пожаловать!\n");
      } else {
          printf("[ОТКАЗ] Неверный ключ! Включена сирена тревоги.\n");
      }

      return 0;
  }
  ```
- **Проверка:** Запустить 2 раза: первый раз ввести `2026` (проверить ветку успеха), второй раз ввести `1234` (проверить ветку отказа).

### Задание 2. «Валидатор диапазона датчика температуры»
- **Файл:** `~/robot_lab/temp_sensor.c`
- **Задача:** Проверить, находится ли температура двигателя марсохода в допустимых пределах (от 10°C до 85°C включительно). Если ниже 10 — включить подогрев. Если выше 85 — включить аварийное охлаждение.
- **Код программы:**
  ```c
  #include <stdio.h>

  int main() {
      int temp = 0;
      printf("Введите текущую температуру двигателя (C): ");
      scanf("%d", &temp);

      if (temp >= 10 && temp <= 85) {
          printf("СТАТУС: Температура в норме (%d C). Двигатели готовы.\n", temp);
      } else if (temp < 10) {
          printf("ВНИМАНИЕ: Двигатель замёрз (%d C). Включаю подогрев!\n", temp);
      } else {
          printf("ТРЕВОГА: Перегрев (%d C)! Активирую жидкостное охлаждение!\n", temp);
      }

      return 0;
  }
  ```
- **Граничные тесты:** Протестировать значения 9, 10, 50, 85, 86.

### Задание 3. «Локализация бага = против ==»
- **Файл:** `~/robot_lab/security_breach.c`
- **Испорченный фрагмент:**
  ```c
  #include <stdio.h>

  int main() {
      int user_role = 0; // 1 = админ, 0 = гость
      printf("Введите код роли (1 или 0): ");
      scanf("%d", &user_role);

      // БАГ: вместо user_role == 1 написано user_role = 1
      if (user_role = 1) {
          printf("СЕКРЕТНАЯ БАЗА ОТКРЫТА ДЛЯ ВСЕХ!\n");
      } else {
          printf("Доступ закрыт.\n");
      }
      return 0;
  }
  ```
- **Симптом:** При вводе `0` программа всё равно пишет «СЕКРЕТНАЯ БАЗА ОТКРЫТА».
- **Действие ученика:** Скомпилировать с `gcc -Wall security_breach.c -o sec`. Увидеть предупреждение: `warning: suggest parentheses around assignment used as truth value`. Исправить на `==` и проверить работоспособность.

## 7. Выходной вопрос и 4 критерия наблюдения

### Краткий выходной вопрос:
> *«В чём катастрофическая разница между строчками if (x == 5) и if (x = 5)? Что делает каждая из них?»*  
> *(Ожидаемый ответ: «if (x == 5) проверяет, лежит ли в x пятёрка, не меняя переменную. А if (x = 5) стирает старое значение, насильно записывает в x число 5 и всегда считает условие верным»)*.

### 4 наблюдения преподавателя:
1. **Использование & в scanf:** Понимает физический смысл передачи адреса ячейки памяти.
2. **Различие = и ==:** Не делает случайных опечаток сравнения.
3. **Логика диапазонов:** Уверенно применяет `&&` для проверки попадания числа в коридор значений.
4. **Тестирование границ:** Сам проверяет граничные значения (edge cases).

## 1. Место урока в общей траектории

- **Конечная способность из `LEARNING_VISION.md`:** Самостоятельно и безопасно собрать электрическую схему на макетной плате (breadboard); рассчитать токоограничивающий резистор; написать и загрузить скетч в микроконтроллер Arduino, управляя цифровыми пинами вывода (`pinMode`, `digitalWrite`); объяснить путь «команда в коде → напряжение на ножке чипа → свечение кристалла светодиода».
- **Текущий этап:** Ядро Этапа 3 («Компьютер и Arduino»).
- **Прошлый освоенный навык (Занятия 6–10):** Ученик уверенно владеет логикой C, понимает структуру памяти, компиляцию и тактовую работу процессора.
- **Причина выбора темы:** До сих пор код жил только внутри виртуального мира экрана и консоли. Сегодня происходит **главное чудо курса**: строчка кода на экране компьютера зажигает настоящий физический огонь — фотоны света на реальной плате на столе! Ученик знакомится с микроконтроллером (компьютером на одном чипе) и базовыми законами электричества.

## 2. Главная учебная цель и проверяемый результат

- **Главная учебная цель:** Понять разницу между компьютером и микроконтроллером; освоить архитектуру платы Arduino Uno, замкнутую цепь, полярность светодиода и управление напряжением пинов через функции `setup()`, `loop()`, `pinMode()` и `digitalWrite()`.
- **Проверяемый результат (действие ребёнка без подсказки):**
  1. Правильно определяет полярность светодиода: длинная ножка — анод (+), короткая ножка со спилом на корпусе — катод (-/GND).
  2. Без подсказки вставляет токоограничивающий резистор (220 Ом) в разрыв цепи и объясняет: *«Если включить светодиод напрямую в 5 Вольт без резистора, пойдёт огромный ток, и кристалл сгорит за долю секунды!»*.
  3. В коде скетча сам меняет задержки `delay()` для генерации осмысленного оптического сигнала (например, сигнал бедствия SOS: 3 коротких, 3 длинных, 3 коротких вспышки).

## 4. Практические задания со схемами и скетчами

### Задание 1. «Канонический Blink (Микроконтроллерный старт)»
- **Скетч Arduino (`blink.ino`):**
  ```cpp
  const int LED_PIN = 13;

  void setup() {
      // Настраиваем пин 13 как цифровой ВЫХОД (источник тока)
      pinMode(LED_PIN, OUTPUT);
  }

  void loop() {
      digitalWrite(LED_PIN, HIGH); // Подать 5 Вольт на пин (зажечь свет)
      delay(500);                  // Ждать 500 миллисекунд (полсекунды)
      digitalWrite(LED_PIN, LOW);  // Снять напряжение (0 Вольт, погасить)
      delay(500);                  // Ждать 500 миллисекунд
  }
  ```
- **Исследование:** Что будет, если убрать строчку `pinMode(LED_PIN, OUTPUT)`? (Пин останется высокоомным входом `INPUT`, тока не хватит, и светодиод будет едва тлеть или не зажжётся вовсе!).

### Задание 2. «Внешняя цепь на макетной плате (Breadboard)»
- **Принципиальная схема:**
  `[Arduino Pin 12]` ➔ `[Резистор 220 Ом]` ➔ `[Анод светодиода (+)]` ➔ `[Катод светодиода (-)]` ➔ `[Arduino GND]`.
- **Расчёт тока по закону Ома:**
  Падение напряжения на красном светодиоде $U_{led} \approx 2.0\text{ В}$. Напряжение питания $U_{cc} = 5.0\text{ В}$.  
  Напряжение на резисторе: $U_R = 5.0 - 2.0 = 3.0\text{ В}$.  
  Ток цепи: $I = \frac{U_R}{R} = \frac{3.0\text{ В}}{220\text{ Ом}} \approx 0.0136\text{ А} = 13.6\text{ мА}$ (идеальный безопасный ток для кристалла светодиода!).

### Задание 3. «Оптический телеграф: Сигнал SOS»
- **Файл:** `sos_beacon.ino`
- **Код:**
  ```cpp
  const int BEACON_PIN = 12;

  // Вспомогательная функция одной вспышки
  void blink_signal(int duration_ms) {
      digitalWrite(BEACON_PIN, HIGH);
      delay(duration_ms);
      digitalWrite(BEACON_PIN, LOW);
      delay(200); // пауза между вспышками
  }

  void setup() {
      pinMode(BEACON_PIN, OUTPUT);
  }

  void loop() {
      // 1. Три точки (буква S): короткие по 200 мс
      for (int i = 0; i < 3; i++) {
          blink_signal(200);
      }
      delay(400); // пауза между буквами

      // 2. Три тире (буква O): длинные по 600 мс
      for (int i = 0; i < 3; i++) {
          blink_signal(600);
      }
      delay(400);

      // 3. Три точки (буква S)
      for (int i = 0; i < 3; i++) {
          blink_signal(200);
      }

      // Пауза перед повторением сообщения
      delay(3000);
  }
  ```

## 6. Дифференциация и развитие

- **Супер-вызов «Безопасность питания»:** Почему максимальный ток одного пина Arduino не должен превышать 20–40 мА, а суммарный ток чипа — 200 мА? Что произойдёт, если подключить напрямую мощный электродвигатель? (Внутренние ключи кристалла перегреются и чип выйдет из строя; для моторов нужны драйверы MOSFET или реле!).

## 7. Выходной вопрос и 4 критерия наблюдения

### Краткий выходной вопрос:
> *«Почему мы обязаны ставить резистор перед светодиодом и что означает строчка pinMode(12, OUTPUT)?»*  
> *(Ожидаемый ответ: «Резистор ограничивает ток, чтобы светодиод не сгорел от перегрузки. А pinMode(12, OUTPUT) открывает электронные ворота пина на вывод, превращая его в источник питания 5 Вольт»)*.

### 4 наблюдения преподавателя:
1. **Электробезопасность:** Не замыкает 5V и GND напрямую, всегда ставит резистор.
2. **Ориентация в полярности:** Безошибочно определяет анод и катод светодиода.
3. **Понимание скетча:** Понимает различие: `setup()` один раз при включении питания, `loop()` крутится вечно.
4. **Перенос знаний C:** Уверенно применяет изученные циклы `for` и функции внутри среды Arduino.

## 8. Необходимые материалы и компоненты

1. Плата Arduino Uno (или Nano) с кабелем USB.
2. Беспаечная макетная плата (Breadboard Half-size).
3. 2 светодиода (красный, синий/зелёный 5 мм).
4. 2 резистора номиналом 220 Ом (цветовая маркировка: красный-красный-коричневый-золотой).
5. Набор соединительных проводов папа-папа (Jumper wires).
6. Ноутбук с Arduino IDE или VS Code + расширение Arduino / PlatformIO.

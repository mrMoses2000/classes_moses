## 1. Место урока в общей траектории

- **Конечная способность из `LEARNING_VISION.md`:** Создавать текстовую программу на C с циклами `while` и `for`; встраивать внутрь цикла логические ветвления; уметь безопасно прерывать выполнение цикла оператором `break` и распознавать бесконечное зацикливание программы.
- **Текущий этап:** Этап 2 («Текст и C на компьютере»).
- **Прошлый освоенный навык (Занятия 6–7):** Ученик уверенно компилирует код, работает с переменными, считывает ввод через `scanf()` и строит ветвления `if / else`.
- **Причина выбора темы:** В Занятии 2 мы познакомились с идеей цикла на визуальной модели робота. Теперь пора перенести эту мощь в настоящий язык Си. Без циклов невозможно обработать поток данных с датчиков (например, непрерывно сканировать горизонт лидаром 50 раз в секунду). Мы научим ученика двум главным формам циклов: циклу со счётчиком `for` и циклу с условием `while`, а также покажем опаснейшую ошибку — **зависание программы (бесконечный цикл)** и спасительное сочетание клавиш `Ctrl + C`.

## 2. Главная учебная цель и проверяемый результат

- **Главная учебная цель:** Освоить синтаксис и семантику циклов `for` и `while` в языке C; научиться применять вложенные условия `if` внутри тела цикла и оператор досрочного выхода `break`.
- **Проверяемый результат (действие ребёнка без подсказки):**
  1. Самостоятельно объясняет три части заголовка `for (int angle = 0; angle < 360; angle += 45)`: старт, условие продолжения и шаг.
  2. При зависании программы мгновенно нажимает `Ctrl + C` в терминале Linux и находит причину: *«В цикле while забыли увеличивать счётчик, условие всегда оставалось истинным!»*.
  3. Применяет оператор `break` для экстренной остановки цикла при обнаружении критической опасности (например, скалы в створе радара).

## 4. Три практических задания

### Задание 1. «Круговой обзор ультразвукового дальномера»
- **Файл:** `~/robot_lab/radar.c`
- **Код:**
  ```c
  #include <stdio.h>

  int main() {
      printf("=== ЗАПУСК ЛИДАРА КРУГОВОГО ОБЗОРА ===\n");

      for (int angle = 0; angle <= 360; angle += 45) {
          printf("Сканирование: азимут %3d градусов... ", angle);

          if (angle == 135) {
              printf("[ВНИМАНИЕ! Обнаружен радиомаяк спасения!]\n");
          } else if (angle == 270) {
              printf("[ПРЕПЯТСТВИЕ: Гранитная скала]\n");
          } else {
              printf("Путь свободен.\n");
          }
      }

      printf("=== ОБХОД 360 ГРАДУСОВ ЗАВЕРШЁН ===\n");
      return 0;
  }
  ```
- **Результат:** Чёткая таблица из 9 измерений с фиксацией двух аномалий.

### Задание 2. «Автономный сбор ресурсов (цикл while)»
- **Файл:** `~/robot_lab/collector.c`
- **Задача:** Робот бурит грунт порциями. Вместимость трюма — 30 кг. Каждая порция даёт по 7 кг. За сколько итераций заполнится трюм?
- **Код:**
  ```c
  #include <stdio.h>

  int main() {
      int cargo = 0;
      int max_cargo = 30;
      int drill_count = 0;

      while (cargo < max_cargo) {
          drill_count++;
          cargo += 7;
          printf("Бурение #%d: загружено +7 кг. Всего в трюме: %d / %d кг\n",
                 drill_count, cargo, max_cargo);
      }

      printf("Трюм заполнен за %d подходов! Возвращаюсь на базу.\n", drill_count);
      return 0;
  }
  ```
- **Исследование:** Почему в трюме оказалось 35 кг, а не ровно 30? Как изменить условие или добавить проверку, чтобы не перегрузить бункер?

### Задание 3. «Укрощение бесконечного цикла»
- **Файл:** `~/robot_lab/infinite_bug.c`
- **Код с ошибкой:**
  ```c
  #include <stdio.h>

  int main() {
      int battery = 5;

      printf("Робот начинает движение...\n");
      // БАГ: забыто battery--; внутри цикла!
      while (battery > 0) {
          printf("Шаг вперёд! Заряд батареи: %d\n", battery);
      }

      printf("Движение окончено.\n");
      return 0;
  }
  ```
- **Симптом:** При запуске программа бесконечно печатает «Шаг вперёд! Заряд батареи: 5», терминал прокручивается с огромной скоростью.
- **Действие ученика:**
  1. Нажать `Ctrl + C` для аварийной остановки.
  2. Найти причину: значение `battery` никогда не уменьшается, поэтому `battery > 0` всегда истинно.
  3. Добавить `battery--;` в тело цикла и убедиться, что программа делает ровно 5 шагов и чисто завершается.

## 7. Выходной вопрос и 4 критерия наблюдения

### Краткий выходной вопрос:
> *«Что произойдёт с компьютером, если в программе запустить бесконечный цикл while(1), и как операционная система Linux позволяет его остановить?»*

### 4 наблюдения преподавателя:
1. **Различие for и while:** Понимает, когда применить счётчик `for`, а когда условие `while`.
2. **Вложенная логика:** Уверенно читает `if` внутри тела цикла.
3. **Реакция на зависание:** Не пугается бесконечного вывода, уверенно жмёт `Ctrl + C`.
4. **Контроль шага:** Следит за инкрементом/декрементом переменных цикла.

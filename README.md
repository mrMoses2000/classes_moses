# «Робот и код» — Занятие 1: «Доставь робота к маяку»

Интерактивный обучающий сайт для проведения очного первого занятия по основам алгоритмов и программирования с учеником 4 класса.

Сайт полностью автономен, работает в браузере без интернета, не требует регистрации, внешних API и компиляторов.

---

## 🚀 Инструкция по запуску

### Запуск на Ubuntu 26.04 LTS (и macOS / Linux)

#### 1. Установка Node.js (требуется Node.js >= 22.12):
```bash
# Проверка наличия Node.js
node -v
npm -v

# Установка Node.js 22 LTS в Ubuntu (если версия ниже 22.12):
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
```

#### 2. Установка зависимостей:
В каталоге проекта выполните:
```bash
npm install
```

#### 3. Запуск сайта:

**Вариант A: Локальный сервер разработки (с горячей перезагрузкой)**
```bash
npm run dev
```
Сайт откроется по адресу: `http://localhost:5173`

**Вариант B: Автономная статическая сборка (рекомендуется для урока без интернета)**
```bash
npm run build
npm run preview -- --host --port 5173
```
Сайт будет доступен:
- На этом ноутбуке: `http://localhost:5173`
- Для планшета/устройства ученика в той же локальной Wi-Fi сети: `http://<IP_АДРЕС_НОУТБУКА>:5173`

#### 4. Запуск тестов:
```bash
# Модульные тесты симулятора и хранилища (Vitest)
npm test

# Сквозные браузерные тесты (автоматически находит Chrome на macOS и Ubuntu):
node scripts/verify-browser.mjs

# Если Chrome установлен в нестандартном месте, укажите переменную CHROME_PATH:
CHROME_PATH=/usr/bin/google-chrome node scripts/verify-browser.mjs
```

## 🎯 Сценарий проведения первого урока (55–60 минут)

| Время | Этап | Действие ученика | Реплика преподавателя |
|---|---|---|---|
| **0–5 мин** | Разминка без компьютера | Рассказывает про опыт в Scratch. Отдаёт 3 команды учителю, чтобы тот дошёл до карандаша | *«Я робот: выполню буквально то, что ты скажешь»* |
| **5–10 мин** | Предсказание (Задание 1) | Смотрит на поле 5×5. Пальцем показывает клетку, куда придёт робот после 3 шагов | *«Сначала покажи пальцем результат, потом нажми Запустить»* |
| **10–20 мин** | Первый маршрут | Сам составляет программу из команд `Шаг`, меняет порядок и длину | *«Какая команда изменила результат?»* |
| **20–32 мин** | Обход преграды (Задание 2) | Прямой путь перекрыт каменной стеной. Ребёнок сначала пальцем чертит путь обхода, затем собирает команды | *«Сколько раз робот повернёт и где? В какую сторону поворот с точки зрения робота?»* |
| **32–42 мин** | Отладка (Задание 3) | Видит готовую программу с ошибкой (`Шаг`, `Поворот налево`, `Шаг`). Запускает, видит расхождение и точечно удаляет лишний поворот | *«Что программа делает сейчас? Где ожидание разошлось с результатом?»* |
| **42–50 мин** | Задание для учителя | Ученик создаёт свой маршрут или усложняет задачу, учитель проходит его программу | *«Как проверить, что твоё задание решаемо?»* |
| **50–57 мин** | Связь с кодом | Открывает кнопку «Показать код», видит текстовые вызовы `step(); turn_left();` | *«Команды те же самые; позже мы научимся писать их словами»* |
| **57–60 мин** | Устная рефлексия | Отвечает на 2–3 вопроса на экране рефлексии | *«Что ты сделаешь первым делом, если робот поедет не туда?»* |

## ⌨️ Управление с клавиатуры

- `1` — добавить команду **«Шаг»**
- `2` — добавить команду **«Повернуть налево»**
- `3` — добавить команду **«Повернуть направо»**
- `Пробел` — **«Запустить»** выполнение программы
- `Backspace` — удалить последнюю команду
- `Escape` — закрыть модальное окно («Показать код» / «План курса»)

## 🧭 Архитектура и гарантии надёжности

1. **Детерминированный симулятор (`src/simulator/engine.ts`):**
   - Чистая функция `(state, command) => nextState`.
   - Проверяет границы поля 5×5, препятствия и маяк.
   - Защита от зависания: лимит максимум 50 команд.
   - Запуск всегда идемпотентно начинается из стартовой клетки задания.

2. **Локальное сохранение (`src/storage/progress.ts`):**
   - Использует `localStorage` только для номера задания, команд и отметок прохождения.
   - Версионирование (`robot_lesson_progress_v1`).
   - Защита от сбоев/битого JSON: безопасный откат к первому заданию.

3. **Панель преподавателя (`src/components/TeacherDrawer.tsx`):**
   - Вызывается незаметной кнопкой «Преподавателю» в углу экрана.
   - Содержит шпаргалку по текущему этапу, ожидаемые трудности, наводящие вопросы и кнопку сброса урока с подтверждением.

4. **Дорожная карта 12 занятий (`src/data/roadmap.ts`):**
   - Доступна по кнопке «План курса» и автоматически открывается после завершения 3 миссий с вопросами для рефлексии.

5. **Дизайн и доступность:**
   - Палитра «Тёплая мастерская», видимые состояния фокуса и крупные элементы управления. Формальный аудит контраста ещё не проводился.
   - Никаких эмодзи в интерфейсе (только контурные SVG-иконки Lucide).
   - Адаптивность: гарантированно помещается без скролла на ноутбуках 1366×768, складывается в одну колонку на мобильных экранах (375px) без горизонтальной прокрутки.
